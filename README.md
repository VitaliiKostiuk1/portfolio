# Портфоліо Frontend-розробника (React + JavaScript + CSS Modules + GSAP)

    npm install
    npm run dev      # розробка
    npm run build    # збірка у dist/

Весь контент (ім’я, email, проєкти, соцмережі, стек) — у `src/data.js`.
Анімації — окремі хуки в `src/hooks/` (поява Hero, скрол, нахил стрічки, ефекти курсора). Кожен компонент має свій `.module.css`.
